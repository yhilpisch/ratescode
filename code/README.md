# Code Overview

This folder contains the chapter scripts for *Python & AI for Rates,
Bonds, and Credit*. Scripts are designed to run from the project root and
to use relative paths into `data/` and `figures/`.

## Figure scripts

`code/figures/` contains deterministic Matplotlib scripts that save figure
PDFs into `figures/`. Run them through `make generated_figures` or the
project validation workflow rather than by copying outputs manually.
